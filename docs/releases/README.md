# Release records

This directory contains the certification and release record of each version.
Planning happens in GitHub issues and milestones. From v1.4.1, each release
keeps a short evidence record, `EVIDENCE.md`, which links to the issues, pull
requests and runs that hold the detail. v1.4.0 keeps its full archived
implementation and release plan.

| Release | Status | Tag target | Execution assurance | Record |
|---|---|---|---|---|
| v1.4.1 | In development | Not tagged | No certification claimed | [Evidence record](v1.4.1/EVIDENCE.md) |
| v1.4.0 | Published | `a5390b4c6ca56ebbd87eca121b5167ee5dc09963` | Microsoft 365 Excel 64-bit: 80 cases, 643 assertions, 0 failures; Office 32-bit remains unverified under [issue #29](https://github.com/danielep71/VBA-PERFORMANCE_MANAGER/issues/29) | [Implementation and release record](v1.4.0/IMPLEMENTATION_AND_RELEASE_PLAN.md) |

The original v1.4.0 plan path remains as a redirect notice to preserve links
from issue comments and external references.

Practices adapted from the maintainer's project template, with their licence
decisions, are recorded in [Template adaptations](../TEMPLATE_ADAPTATIONS.md).
